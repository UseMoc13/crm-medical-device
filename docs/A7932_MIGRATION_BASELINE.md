## Install to an empty database (never run against an existing partial schema)

1. Use PostgreSQL 18 and its psql client on PATH, PHP pgsql extension, composer dependencies. Use a database owner with permission to install pgcrypto. Confirm local target; localhost tunnels can reach remote servers. Do not run migrate:fresh or rollback historical baseline migrations. Do not run schema:dump --prune. Keep the baseline under version control. Only run against an explicitly created empty database. No sessions table in baseline; use SESSION_DRIVER=file and a writable storage/framework/sessions. DB_URL must be absent/blank; confirm actual connection. Do not use sqlite for CRM installation.
2. Configure Laravel .env for the new local DB, APP_ENV=local, DB_CONNECTION=pgsql, DB_HOST=127.0.0.1, DB_PORT=5432, DB_DATABASE=<new database>, DB_USERNAME/DB_PASSWORD locally, SESSION_DRIVER=file. Configure APP_KEY as usual for a new clone; do not regenerate an existing project's APP_KEY. Clear cached config before migrating. Stop workers and web server during testing. Use a new DB name for rehearsal, no changes to prototype.
3. Run `php tools/a7932_quick_check.php` (offline exact checkpoint). Check `psql --version` and `php artisan db:show` against the new DB; `php artisan migrate` loads the Laravel-native pgsql-schema.sql, including the migration ledger, then runs only newer pending migrations. Baseline uses ON_ERROR_STOP and a transaction plus an empty public-schema guard. Laravel itself may create/drop an empty migration tracking table before load. Do not run on an existing partial schema. If failure occurs, stop; do not retry with fresh/reset.
4. `psql -X -v ON_ERROR_STOP=1 -h 127.0.0.1 -p 5432 -U postgres -d <new database> -f tools/a7932_verify_fresh.sql` checks exact table/permission/migration names, counts and 63 empty tables; run before bootstrap. `php artisan migrate:status` should show 32 Ran. `php artisan db:seed --class=CrmPermissionCatalogSeeder` optionally checks idempotent catalogue seeding; repeat fresh verification. Bootstrap only after fresh verification with `php artisan crm:super-admin:bootstrap` (local, password privately chosen). No default credentials. For non-local installation use audited provisioning.
5. Existing database with all 32 migrations applied: normal migrate does not reload baseline. This does NOT repair a partially migrated database. Never inject migration records into an existing partial DB or roll back across baseline checkpoint; use a planned forward migration or restore. Future migrations should be additive and newer than checkpoint. Do not regenerate this baseline without auditing schema and catalogue, including migration history. Existing custom permission definitions/role grants are not reproduced; review them explicitly if needed.
